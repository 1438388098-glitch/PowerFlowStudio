# PowerFlowStudio 使用教程

> 10 分钟上手: 从拖出第一个母线, 到跑 OPF 最优潮流和 N-1 校核。

## 1. 安装与启动

```bash
pip install -r requirements.txt        # 运行依赖 (锁版本)
python app.py                          # 启动 GUI
python app.py my_grid.json             # 直接打开已有拓扑
```

## 2. 界面导览

| 区域 | 内容 |
|------|------|
| 左侧 | 元件库: 母线 / 电源 / 负荷 / 变压器 / 阻抗 / 电容电抗器 |
| 中间 | 画布: 自由拖拽、连线、滚轮缩放(光标锚点)、中键平移 |
| 右侧 | 属性面板: 选中元件/连线的参数编辑与潮流结果 |
| 底部 | 潮流结果总览: 母线表 / 支路表 / 电压图 / 相角图 (可关, 点行可定位画布) |
| 右下 | 小地图(视图菜单开启)、模式指示(AC/DC)、元件统计、光标坐标 |

## 3. 搭一个电网 (3 步)

1. 从元件库**按住拖出**几个母线和电源、负荷。电源/负荷放置时会自动吸附到 200px 内最近母线 (没有母线则自动新建)。
2. 从元件**边缘的小圆点(端口)**拖到另一元件, 松手建立连线:
   - 母线 ↔ 母线 = 线路 (可调 r/x/长度/载流量)
   - 母线 ↔ 变压器/阻抗 = 把母线焊到该元件对应侧
   - 电源/负荷 ↔ 母线 = **改挂接母线** (拖线即转正, 不再是视觉装饰)
3. 点 ▶ 运行潮流 (Ctrl+R)。母线按电压着色 (绿=正常/黄=越限/红=严重/灰=孤立), 连线按负载率着色并标注 P/负载率。

## 4. 计算功能

| 功能 | 入口 | 说明 |
|------|------|------|
| 牛顿-拉夫逊潮流 | ▶ / Ctrl+R | 默认 AC 潮流 |
| 直流潮流 | 勾选 "DC 直流模式" | 只算有功/相角, 快 |
| OPF 最优潮流 | 计算 → 🎯 OPF | 发电成本最小化调度; 选中发电机设成本(元/MWh)与出力上下限 |
| 三相短路 | 计算 → 三相短路 | 最大/最小方式, 母线 Ikss 显示在属性面板与母线 CSV |
| N-1 校核 | 计算 → ⛏ N-1 | 逐条开断线路/变压器, 报告越限与孤立母线, 可导出 txt |
| IEEE 标准算例 | 计算 → IEEE 14/24/30/39/57/118 | 一键加载并自动计算 |

> 注意: OPF 与短路会互相覆盖结果字典, 切换计算类型后重跑即可。

## 5. 电压调节三件套

- **变压器分接头**: 选中变压器, 属性面板 "分接头位置" -2..2 档。
- **并联电容/电抗器**: 元件库拖出 "电容/电抗", q_mvar 正=电抗器(吸收)/负=电容器(发出)。
- **平衡节点位置**: 勾选任一发电机 "平衡节点(Slack)" 改变参考点。

## 6. 编辑效率

- **复制/粘贴**: Ctrl+C / Ctrl+V (新 uid、名字顺延、两端都复制的线路一并带过去)
- **撤销/重做**: Ctrl+Z / Ctrl+Shift+Z (增删/连线/拖动/参数修改/粘贴全可撤销)
- **搜索定位**: Ctrl+F 输入名字回车, 画布自动选中并居中
- **多选对齐**: Ctrl+点选多个元件 → 右键 → 对齐/分布 (水平/垂直中线、左右上下、等间距)
- **改参数**: 右侧面板即改即生效; 一次编辑(到失焦/回车)算一条撤销记录

## 7. 保存 / 载入 / 导出

- `Ctrl+S` 保存 (原子写, 防中途崩溃毁档); 文件 → 另存为
- 每 3 分钟自动保存一次脏画布 (轮转 3 份, 系统临时目录); 文件 → 恢复自动保存
- 文件 → 导出结果 CSV: 母线 / 支路 / 电源与负荷 三个表 (utf-8-sig, Excel 直开)
- 文件 → 导出画布 PNG: 2 倍分辨率白底, 报告直接用

## 8. 快捷键速查

| 键 | 功能 | 键 | 功能 |
|----|------|----|------|
| Ctrl+R | 运行潮流 | Ctrl+F | 搜索元件 |
| Ctrl+S | 保存 | Ctrl+N | 新建 |
| Ctrl+Z / Ctrl+Shift+Z | 撤销 / 重做 | Ctrl+C / Ctrl+V | 复制 / 粘贴 |
| Ctrl+0 | 适配视图 | Delete | 删除选中 |
| ESC | 取消连线/选中 | 滚轮 | 缩放 |

## 9. 常见问题

- **提示 "至少需要一个电源"**: 电网要有发电机作为平衡节点。
- **"发电机 xx 挂接的母线不存在"**: 元件的挂接母线被删了, 在属性面板重新选一条母线。
- **变压器无法创建/计算报同侧**: 变压器两侧必须接两条不同母线 (创建时会自动避让)。
- **画布显示 "未连通" 灰色**: 该母线没连入任何电源网络, 潮流解为 NaN。
- **4K / 高分屏上界面字号偏小或偏大**: 程序会自动跟随系统缩放。若系统把缩放设成
  100% 但屏幕是 4K, 可手动指定倍数: `POWERFLOW_UI_SCALE=1.5 python app.py`
  (Windows cmd: `set POWERFLOW_UI_SCALE=1.5 && python app.py`)。
- **窗口跑到了屏幕外 / 属性面板特别窄**: 多为旧版本留下的窗口几何。程序启动时会自动
  校验并纠正; 也可删掉配置项 `HKCU\Software\PowerFlowStudio\PowerFlowStudio` 重置。
- **哪里看崩溃日志**: 帮助 → 系统信息 里列出了日志文件路径(系统临时目录)。
  同一个对话框还会显示当前屏幕尺寸、缩放倍率与实际生效的界面倍数。
